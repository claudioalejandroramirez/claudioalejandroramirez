### 🧵 The Story: From Servers to the Cloud (and Beyond)

**Chapter I — The Foundation (2010–2021)**

My journey started where the internet lives: inside a data center. At **IBM** (as an intern and later as a Security Analyst via Decision Group), I was hands-on with physical servers, patch management for enterprise clients like Carrefour, Leroy Merlin, and Telefônica, and running incident queues using **ITIL v3** methodology. From there, I led IT departments, built network infrastructure from scratch, and ran full on-premises environments with VMware, Windows Server, Linux, VoIP, and firewall management.

That foundation — understanding infrastructure at the metal level — is what makes my cloud designs different.

---

**Chapter II — The Cloud & Data Pivot (2021–2023)**

In 2021, I made a deliberate move: I dove deep into cloud and data. Supporting that bet academically, I enrolled in a **Postgraduate program in Data Engineering at PUC Minas** and a **Software Engineering degree at Anhanguera** — while working full-time.

At **Omie**, I integrated APIs, maintained SQL database integrity, and managed cloud identity with Azure Entra ID and Active Directory. It was the bridge between legacy sysadmin work and modern cloud operations.

---

**Chapter III — The Architect (2023–Present)**

At **Exame (BTG Pactual Group)**, I stepped fully into the solutions architect role — designing multicloud architectures across AWS and GCP, building data pipelines, and leading technical decisions that impacted millions of users:

- 🗳️ **Election Coverage Infrastructure**: Designed a fault-tolerant, multi-AZ/multi-region AWS + GCP architecture for massive real-time traffic peaks, using EKS, ECS Fargate, Lambda, CDN (Azion), and Grafana for centralized observability.
- 📊 **Data Modernization**: Led the migration of a legacy data environment to a lean Google Cloud architecture with Cloud Composer (Airflow), Pub/Sub, Cloud Functions, and BigQuery.
- 🤖 **Omnichannel AI Integration**: Architected a hybrid system integrating AI chatbots with on-premises legacy telephony infrastructure (Cisco URA) via API.
- 🔐 **Lead Intelligence Platform**: Designed a multicloud data pipeline (GCP BigQuery → AWS S3 via AppFlow + Glue) with KMS encryption and TLS for marketing and financial intelligence.

At **Inetum**, I delivered two flagship projects:
- **Vivo/Telefônica (BMC)**: Led security automation, hardening, and patch management across thousands of on-premises hosts — **delivered Go Live**, ensuring stable and secure operation of the solution.
- **BYD – São Paulo Metro Line 17 (SkyRail)**: Technical lead for the hyperconverged infrastructure architecture of the project's control room, SIMEA environment, and data center — **validated and updated the Design Review**, from architecture definition to vendor management.

### 🧵 A Trajetória: De Servidores à Nuvem (e Além)

**Capítulo I — A Base (2010–2021)**

Minha jornada começou onde a internet vive: dentro de um data center. Na **IBM** (como estagiário e, depois, como Analista de Segurança via Decision Group), fui hands-on com servidores físicos, gestão de patches para clientes enterprise como Carrefour, Leroy Merlin e Telefônica, e condução de filas de incidentes usando a metodologia **ITIL v3**. De lá, liderei departamentos de TI, construí infraestruturas de rede do zero e gerenciei ambientes on-premises completos com VMware, Windows Server, Linux, VoIP e firewall.

Essa base — entender infraestrutura no nível do hardware — é o que torna meus designs de nuvem diferentes.

---

**Capítulo II — A Virada para Nuvem e Dados (2021–2023)**

Em 2021, fiz uma aposta deliberada: mergulhei fundo em cloud e dados. Para sustentar essa aposta academicamente, cursei **Pós-graduação em Engenharia de Dados na PUC Minas** e **Engenharia de Software na Anhanguera** — enquanto trabalhava em tempo integral.

Na **Omie**, integrei APIs, mantive a integridade de bancos de dados SQL e gerenciei identidade cloud com Azure Entra ID e Active Directory. Foi a ponte entre o trabalho de sysadmin legado e as operações modernas de nuvem.

---

**Capítulo III — O Arquiteto (2023–Presente)**

Na **Exame (Grupo BTG Pactual)**, assumi plenamente o papel de arquiteto — desenhando arquiteturas multicloud em AWS e GCP, construindo pipelines de dados e liderando decisões técnicas que impactaram milhões de usuários:

- 🗳️ **Infraestrutura para Cobertura de Eleições**: Arquitetura tolerante a falhas, multi-AZ/multi-region em AWS + GCP para picos massivos de tráfego em tempo real, com EKS, ECS Fargate, Lambda, CDN (Azion) e Grafana para observabilidade centralizada.
- 📊 **Modernização de Dados**: Liderança da migração de ambiente legado para uma arquitetura enxuta no Google Cloud com Cloud Composer (Airflow), Pub/Sub, Cloud Functions e BigQuery.
- 🤖 **Integração de IA Omnichannel**: Arquitetura de sistema híbrido integrando chatbots com IA à infraestrutura de telefonia legada on-premises (Cisco URA) via API.
- 🔐 **Plataforma de Inteligência de Leads**: Pipeline de dados multicloud (GCP BigQuery → AWS S3 via AppFlow + Glue) com criptografia KMS e TLS para inteligência de marketing e financeira.

Na **Inetum**, entreguei dois projetos emblemáticos:
- **Vivo/Telefônica (BMC)**: Liderança da automação de segurança, hardening e gestão de patches em milhares de hosts on-premises — **Go Live entregue**, garantindo operação estável e segura da solução.
- **BYD – Linha 17 do Metrô de São Paulo (SkyRail)**: Líder técnico da arquitetura de infraestrutura hiperconvergente da sala de controle, ambiente SIMEA e data center — **validação e atualização do Design Review**, da definição da arquitetura à gestão de fornecedores.
